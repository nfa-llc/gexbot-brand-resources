# Typography

The `gexbot` wordmark and primary UI typeface is **Agrandir** (weight: Regular).

- Font file: [`font/Agrandir-Regular.otf`](font/Agrandir-Regular.otf)
- Fallback stack: `"Agrandir", -apple-system, "Segoe UI", Roboto, sans-serif`
- Always write the product name `gexbot` in lowercase, in lockups **and** in prose. Never write `Gexbot`,
  `GexBot` or `GEXBOT`.
  - Use lowercase at the start of a sentence: "gexbot sends the levels at 9:30 ET."
  - Use lowercase in headings, page titles, email subjects, buttons, labels and alt text.
  - In a title-case heading, capitalize the other words but not the brand: "Connect gexbot to NinjaTrader".
- Names on a third-party platform follow the rule too: plugin indicator, study and add-on names, download file
  names, and partner products that carry the name. Write `gexbot`, `gexbot Orderflow Live`, `gexbot_ctrader.algo`
  and "PND gexbot".
- Only these keep their exact form: code identifiers (`GexbotSettingsController`) and the legal trademark notice,
  which registers the mark as `GEXBOT`.
- The registered trademark mark (™) is part of the wordmark artwork itself (see `svg/wordmark/` and
  `svg/inline/`) - do not re-typeset the wordmark by hand, always use the vector source.
