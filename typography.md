# Typography

The `gexbot` wordmark and primary UI typeface is **Agrandir** (weight: Regular).

- Font file: [`font/Agrandir-Regular.otf`](font/Agrandir-Regular.otf)
- Fallback stack: `"Agrandir", -apple-system, "Segoe UI", Roboto, sans-serif`
- Always write the product name `gexbot` in lowercase. Never capitalize as `Gexbot` or `GEXBOT` within
  branding lockups (this differs from prose usage in sentences, where normal capitalization rules apply).
- The registered trademark mark (™) is part of the wordmark artwork itself (see `svg/wordmark/` and
  `svg/inline/`) - do not re-typeset the wordmark by hand, always use the vector source.
